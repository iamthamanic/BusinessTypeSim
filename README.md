# Business Type

Mobile-first CEO decision simulation built with React, TypeScript, Vite and Capacitor.

## Current branch

`chore/project-setup` contains the first playable mobile core-loop shell with three company scenarios, a free-form decision composer, Decision Quality preview and Decision Ledger.

## Stack

- React + TypeScript + Vite
- Capacitor for Android and iOS
- Supabase client and cloud adapters
